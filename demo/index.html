An AI that pays the company's bills.
Would you ship it? We made it safe to.

Ledger approves invoices, changes vendor bank details and releases payments. It's fast, helpful, and it falls for every scam in the inbox. We can't change the agent or its model, so we put Jev-backed policies in front of every tool call it makes.

The core idea

Stop the bad payment before it's born.

Everyone else: “Let's audit the payments after they go out, find the fraud, and chase the money.”

Us: “Why don't we just catch the bad transfer before it happens?”

“Alright, let's try your plan.”

A wire transfer can't be undone. So Ledger never gets to make a risky call unchecked: every tool call is judged before it runs. If it breaks the finance policy, it's blocked, and the agent is told what to do instead, so it recovers and still finishes the job.

What we built

A Jev guard that generalises

Before any state-changing call (pay, change bank details, approve, write off, post, reply), Jev gets Ledger's own policy manual, what the requester actually asked, the session so far, and the proposed call. It returns typed verdicts, and any “yes” above 0.8 blocks the call with a redirect. No rule mentions a specific trap, so it catches cases nobody wrote a rule for. The same code works for any agent that has a handbook.
